# Testing Life in the UK — support site

Static site for the **Testing Life in the UK** iOS app. Hosts the public
support page and the privacy policy referenced by the App Store listing.

## Pages

- `index.html` — landing page and support contact.
- `privacy.html` — full privacy policy.

## Hosting
